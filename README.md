# 개인택시 운행일지 대시보드

영수증(미터기, 가스) 사진을 올리면 자동으로 값을 읽어서 구글 시트에 기록하고, 순수익과 연비, 실차율 등을 그래프로 보여주는 개인용 앱입니다. 폰 브라우저에서도 잘 보입니다.

이 폴더는 회사 업무 폴더와 완전히 분리된 개인 전용 공간입니다.

## 담긴 것

- `app.py` 앱 본체
- `requirements.txt` 필요한 파이썬 패키지 목록
- `migrated_taxi_2026.csv` 옮겨둔 과거 데이터(1~7월)
- `.streamlit/secrets.toml.example` 비밀 값 채우는 양식
- `.gitignore` 비밀 값이 깃헙에 안 올라가게 막는 설정

## 이 폴더를 다른 PC로 옮기는 법

두 가지 중 편한 걸로 하세요.

### 방법 1. 폴더째 복사 (제일 간단)

1. 이 폴더 전체를 새 PC로 복사 (USB, 클라우드 드라이브 등)
2. 새 PC에서 파이썬 설치 후 아래 실행법대로

`.streamlit/secrets.toml` 은 비밀 값이라 복사할 때 같이 챙기세요. 깃헙엔 안 올라갑니다.

### 방법 2. 깃헙으로 (버전 관리 + 온라인 배포까지)

- 개인 깃헙 계정에 올린 뒤, 새 PC에서 `git clone` 으로 내려받기
- `secrets.toml` 만 따로 새로 만들면 됨 (양식은 `.example` 참고)

## 로컬에서 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리고 `http://localhost:8501` 에서 확인됩니다.

## 온라인으로 올려서 폰에서 쓰기 (무료)

1. 이 폴더를 개인 깃헙 계정 저장소에 올림
2. share.streamlit.io 에서 그 저장소 연결
3. 앱 설정의 Secrets 칸에 `secrets.toml` 내용 붙여넣기
4. 생성된 주소를 폰 브라우저에 저장해두고 사용

## 연결에 필요한 것 (한 번만 세팅)

- Claude API 키
- 구글 서비스 계정 (구글 클라우드에서 무료 생성 후, 새 시트를 그 계정 이메일로 공유)
- 새 구글 시트 (과거 데이터 CSV를 가져오기로 넣어두면 됨)

세팅 안 된 상태에서도 과거 데이터로 그래프 보기는 됩니다.
